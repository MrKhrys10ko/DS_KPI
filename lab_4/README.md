\# Лабораторна робота 4: Візуалізація гармоніки та фільтрація



\## Завдання

Створити програму з інтерактивним інтерфейсом для малювання гармоніки $y(t) = A \\cdot \\sin(\\omega t + \\phi)$, накладання шуму та його фільтрації.

Вимоги до системи та середовища:
Версія Python: 3.9 або вище.
Операційна система: Windows 10/11, macOS або Linux.



\## Налаштування та запуск

1\. Створіть віртуальне середовище:

&#x20;  python -m venv venv



2.Активуйте його:

Windows: venv\\Scripts\\activate

macOS/Linux: source venv/bin/activate



3.Встановіть requirements:

pip install -r requirements.txt



4.Запустіть програму



Інструкція користувача:

&#x09;Керування параметрами:

&#x09;	1.Слайдери гармоніки (Amplitude, Frequency, Phase): дозволяють змінювати амплітуду, частоту та фазовий зсув "чистого" сигналу.

&#x09;	2.Слайдери шуму (Noise Mean, Noise Covariance): налаштовують середнє значення та дисперсію випадкового шуму.

&#x09;	3.Слайдер Cutoff Frequency: регулює частоту зрізу фільтра низьких частот Баттерворта. Чим нижче значення, тим сильніше згладжується сигнал.

&#x09;	4.Чекбокс Show Noise: перемикає видимість помаранчевої лінії зашумленого сигналу на графіку.

&#x09;	5.Кнопка Reset: миттєво повертає всі повзунки та стан графіка до початкових значень.

&#x09;Легенда графіка:

&#x09;	1.Помаранчева лінія: зашумлена гармоніка (вхідний сигнал для фільтрації).

&#x09;	2.Синя пунктирна лінія: ідеальна "чиста" гармоніка.

&#x09;	3.Фіолетова лінія: результат роботи фільтра, який має бути максимально наближеним до чистого сигналу.
