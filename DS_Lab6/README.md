# Лабораторна робота №6 Обробка відеопотоку за допомогою OpenCV

**Опис:** C++ програма для захвату відео з веб-камери в реальному часі з модульною архітектурою.

## Функціонал
- Зміна режимів клавішами `1`-`5`: Normal, Invert, Blur, Canny, Glitch.
- Повзунок (Trackbar) для регулювання яскравості.
- Малювання мишкою (ЛКМ — малювати червоним, ПКМ — очистити).

## Інструкція
```bash
./preinstall.sh
./build.sh
./run.sh

## Вимоги до системи
- **Операційна система:** Linux (Kali Linux / Ubuntu 22.04 LTS або новіша)
- **Компілятор:** GCC / G++ з підтримкою стандарту C++17
- **Система збірки:** CMake 3.10+
- **Апаратні вимоги:** Наявність підключеної веб-камери (або налаштованого USB-фільтра у VirtualBox)
