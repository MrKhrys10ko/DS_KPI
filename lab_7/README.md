## Опис архітектури проєкту (Lab 7)
Програма побудована за модульним принципом із використанням багатопотоковості:

- **main**: Ініціалізує всі модулі, керує головним циклом програми та обробляє повзунок яскравості.
- **CameraProvider**: Відповідає за стабільне захоплення відеопотоку з веб-камери (`/dev/video0` або `/dev/video1`), має підстраховку у вигляді запуску з файлу.
- **Display**: Ізольований модуль для створення графічного вікна та виведення фінального обробленого кадру.
- **KeyProcessor**: Обробляє гарячі клавіші (`1`-`7`, `q`, `ESC`) та зберігає поточний стан (`enum class Mode`).
- **FaceDetector**: Головний фоновий модуль нейромережі (ResNet-10). Містить робочий потік `std::thread`, який асинхронно виконує `net.forward()`. Спільні дані захищені за допомогою `std::mutex`, а синхронізація реалізована через `std::condition_variable`.
- **FrameProcessor**: Обробляє ефекти (інверсія, розмиття, глітч, малювання мишкою) та накладає рамки детекції облич (червоні для однопотокового режиму, зелені — для багатопотокового).
