\# Лабораторна робота 5. Наука про дані: обмін результатами та початковий аналіз



\### Опис

Ця програма побудований на базі бібліотеки Streamlit. Вона дозволяє переглядати дані індексів VCI, TCI, VHI, фільтрувати їх за регіонами, роками та тижнями, а також візуалізувати часові ряди.



\### Інструкції по запуску

1\. Встановити requirements: `pip install -r requirements.txt`

2\. Запустити програму: `streamlit run main.py`
