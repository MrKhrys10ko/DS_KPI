## Опис проекту
Проект присвячений аналізу великих масивів даних за допомогою Pandas.

## Налаштування та запуск
1. Створіть віртуальне середовище: `python -m venv venv`
2. Активуйте його:
   - Windows: `venv\Scripts\activate`
   - Linux/macOS: `source venv/bin/activate`
3. Встановіть залежності: `pip install -r requirements.txt`
4. Запустіть Jupyter: `jupyter notebook`
